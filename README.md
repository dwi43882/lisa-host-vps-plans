## 免备案到底免掉了什么

大陆境内服务器有强制的 ICP 备案要求，机房在境外就没有这道流程。备案本身不收费，但要 7 到 20 天，期间域名打不开；材料写错、核验单照片拍糊、域名所有者信息对不上，都会被打回重来，一来一回就是一周起。

所以“免备案”省的是时间和流程，不是监管。这点需要说清楚：备案是中国大陆境内的监管要求，境外服务器不受工信部管辖，个人或企业用境外服务器托管网站本身不违反中国法律。但如果你的网站面向大陆用户做经营性服务，比如电商、SaaS、收费会员，该遵守的业务法规一样要遵守。备案和合规是两件事，别混。

香港是个特殊选项。行政上它属于中国特别行政区，互联网管理体系与内地不同，域名解析到香港服务器同样不需要 ICP 备案；地理位置又离广州只有一百多公里，走优化线路的话，内地访问延迟能压到几十毫秒。免备案和低延迟这两件事，在香港节点上能同时成立，这也是它比美国节点贵的原因。

## 常见问题

**免备案 VPS 合法吗？**
合法。备案是中国大陆境内的监管要求，境外服务器不受工信部管辖，用境外服务器托管网站本身不违反中国法律。面向大陆用户的经营性服务仍需遵守国内相关业务法规，这是另一件事。

**香港和美国到底差多少？**
延迟上，香港优化线路内地访问几十毫秒，美国两百毫秒上下，差一个数量级。价格上，同样是 1 核 1G 年付，美国 199 元起，香港 566 元起，差 367 元/年。访客在国内就选香港，访客在海外就选美国，别为了省三百多块让国内用户每次打开都等两秒。

**流量用超了会怎样？**
LisaHost 官方页面没有公开超量后的具体处理规则，计量套餐超限是按限速还是按其他方式处理，下单前建议直接问客服确认。不想操心这件事就直接选不限流量款，但先对照上面那笔 810 元/月的账，看值不值。

**能退款吗？**
可以。官方对表内所有套餐都标了 **48 小时不满意无条件退款**，这是这家相对少见的政策，也是第一次买最该用上的东西。超过 48 小时之后的处理方式官方没写明，别默认它还能退。

**能装 Windows 吗？**
官方香港页面标注支持安装 Windows。买之前确认一下你要的套餐是否包含授权，别装完才发现要额外付费。

**原生 IP 和住宅 IP 有什么不一样？**
原生 IP 指这个 IP 段归属于当地运营商、地理定位真实，不是被转售多次的“假本地 IP”。住宅 IP 更进一步，来自真实家庭宽带线路，平台风控看来就是普通用户。做跨境电商和社媒运营，两者都比普通机房 IP 强，住宅 IP 更彻底，也更贵。
